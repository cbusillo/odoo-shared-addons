## Product proof and upstream

The product can opt individual hierarchy views into the chart after installing
the addon. For Employees, configure the officer and public employee hierarchy
views independently so each action continues to use its own model and rules.
Confirm the correct views, Odoo search, card fields and form opening as both
roles in a disposable product preview with synthetic data.

After product proof and Director review of the exact submission, the generic
addon is a candidate for [OCA/web](https://github.com/OCA/web). Carry the
manifest, README fragments, tests and vendor notices into its target branch,
use the repository’s module template and checks, and include desktop and
mobile captures of synthetic data with the proposal.
